# ADR-001: Use a TurboModule for the first release

- Status: Accepted
- Date: 2026-10-09

## Decision

The first release (MVP) is a plain React Native TurboModule, not an Expo Module or a Nitro Module.

## Why

- Expo Modules and Nitro need extra configuration and analysis. Kept simple for the MVP.

## Revisit when

Issues or feedback show a need. A Nitro comparison may come later.
